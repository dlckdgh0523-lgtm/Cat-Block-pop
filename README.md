# Cat Block Pop

고양이 콘셉트를 활용한 블록 게임 프로젝트입니다.  
귀여운 비주얼과 인터랙션 중심의 UI를 구현하면서, 프론트엔드 구조 설계와 사용자 경험 흐름을 함께 다듬는 데 초점을 맞췄습니다.

## 프로젝트 소개

이 프로젝트는 단순히 "고양이 테마 게임"을 만드는 것보다,
- 블록 기반 게임 인터랙션
- 사용자에게 직관적인 화면 흐름
- 감성적인 콘셉트와 플레이 경험의 결합

을 실험해보기 위해 만들었습니다.

## 핵심 기능

- 블록 게임 기반 인터랙션
- 고양이 콘셉트의 UI/비주얼 구성
- 드래그 앤 드롭 기반 상호작용 구조
- 반응형 웹 환경 고려
- Supabase 연동 확장 가능 구조

## 기술 스택

- **Frontend**: React, Vite
- **Language**: TypeScript
- **UI**: MUI, Radix UI, Tailwind CSS
- **Interaction**: React DnD
- **Data / Backend**: Supabase
- **Animation / UX**: Motion

## 내가 집중한 부분

- 게임과 UI 사이의 균형 잡기
- 사용자가 직관적으로 이해할 수 있는 화면 흐름 구성
- 귀여운 콘셉트가 실제 플레이를 방해하지 않도록 조정
- 추후 기록 저장 / 랭킹 / 사용자 데이터 연동이 가능하도록 구조 잡기

## 기술적 고민

### 1. 테마성과 가독성의 균형
고양이 콘셉트를 강조하되, 실제 플레이에 방해가 되지 않도록 UI 밀도를 조절하는 것이 중요했습니다.

### 2. 인터랙션 설계
단순히 예쁜 화면보다, 사용자가 조작하는 순간 자연스럽게 반응하는 UI를 만드는 데 중점을 두었습니다.

### 3. 확장성
Supabase 관련 구조가 포함되어 있어 이후 기록 저장, 사용자별 데이터 관리, 랭킹 기능 등으로 확장하기 좋게 설계하려고 했습니다.

## 아쉬운 점

- 게임 규칙과 점수 시스템을 더 명확히 문서화할 필요가 있습니다.
- 화면 캡처 및 데모 정리가 아직 부족합니다.
- 실제 운영 기준의 상태 관리 구조를 더 보강할 수 있습니다.

## 향후 개선 계획

- 사용자 기록 저장
- 랭킹 기능 추가
- 사운드 / 효과 연출 개선
- 모바일 UX 최적화
